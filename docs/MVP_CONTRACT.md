# MVP 合同：预录音频驱动数字人

状态：`READY`  
版本：2026-09-25-v1

## 目标

输入一张单人参考图、一段 5-10 秒预录语音和一条简短提示词，输出身份基本稳定、口型随语音变化、保留输入音轨内容与时长的单人数字人视频。

## 输入

- 一张 PNG/JPEG 单人参考图，脸部清晰，首轮使用正面或轻微侧脸。
- 一段 WAV 音频，5-10 秒；模型内部可重采样，但必须保留原始文件和时间轴。
- 一条描述人物状态、环境和动作幅度的文本提示词。
- 首轮只支持一个人物、一个连续镜头和预录音频。

## 输出

- 可正常解码的 MP4。
- 视频和输入音频从同一时间零点开始。
- 最终封装优先复用输入音轨；不得生成、删除或改写语音内容。
- 必须记录分辨率、FPS、音频采样率、总时长和模型 revision。

## 首轮验收

- 固定输入和 seed 可重复完成一次端到端生成。
- 输出音画轨道均存在且可解码。
- 音频内容不变；输出与输入时长差不超过一帧或 50 ms 中的较大值。
- 人脸在主体片段内可识别，不能出现持续性严重身份崩坏。
- 口型相对无音频条件基线具有可观察改善；正式量化阈值在获得首批样本后预注册。
- 记录模型加载时间、生成时间、峰值显存和输出路径。

## 本轮不做

- 实时麦克风、双人或多人对话。
- 全量 TalkVerse 下载或训练。
- H3 AR/DMD 训练。
- 公网服务、商业使用或模型发布。
- 把单个主观样例作为模型有效性结论。

## 基线顺序

1. TalkVerse-5B：验证预录音频驱动任务链路。
2. MiniMax H3/SolarWM-H3：验证目标基座与单 A100 可运行性。
3. FlashHead：验证后续实时服务接口。

只有前两个模型基线形成可复现记录后，才开始 TalkVerse 小样本数据管线和 H3 外部音频条件实验。
